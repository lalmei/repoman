## Getting Help

If you encounter issues:

1. **Check [Troubleshooting](../reference/troubleshooting.md)** for general/CLI/Copier issues, or [Testing Troubleshooting](testing-troubleshooting.md) for test-specific issues
2. **Search existing issues** in the project repository
3. **Create a new issue** with detailed information about the problem
4. **Ask in the project discussions** or community channels
