# Repoman

A Python project generator and repository management tool.

**Quick links:** [CLI reference](cli.md) · [Make commands](make-commands.md) · [The template](template.md) · [Roadmap](roadmap.md) · [Development guide](development/README.md) · [Testing guide](development/testing.md)

Quick start: install with `uv sync`, run `make test`, then generate a project with `uv run repoman create my-project`. See the [CLI reference](cli.md) for subcommands and options, and the [Development guide](development/README.md) for setup and workflows.
