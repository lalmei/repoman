# Repoman

A Python project generator and repository management tool.

**New here?** Start with [Installation](getting-started/installation.md) and [Quick start](getting-started/quickstart.md).

**Quick links:** [CLI reference](cli.md) · [Make commands](make-commands.md) · [The template](template.md) · [Roadmap](roadmap.md) · [Development guide](development/README.md) · [Testing guide](development/testing.md) · [Troubleshooting](reference/troubleshooting.md)

Quick start: install with `uv sync`, run `make test`, then generate a project with `uv run repoman create my-project`. See the [CLI reference](cli.md) for subcommands and options, and the [Development guide](development/README.md) for setup and workflows. For a visual map of how the docs connect, see [Documentation map](development/documentation.md#documentation-map).
